About this demo

This single-page application demonstrates cross-channel identity stitching between a web session and a native Android app, both powered by Adobe Experience Platform.

When you browse this page, Adobe Web SDK (alloy.js) collects your anonymous ECID. When you tap Open in app, that ECID is appended to the deep link URL. The native app reads it, adds it as a secondary identity alongside its own ECID, and sends both to AEP Edge Network.

AEP then automatically stitches the two anonymous profiles — the web visitor and the app visitor — into a single profile in Real-Time CDP and CJA.

Identity flow

The web ECID is passed to the app via:
adobedemoapp://?web_ecid=<ECID>

Inside the app, both identities are sent to AEP Edge with every event:

identityMap.ECID[0] → app ECID (primary: true)
identityMap.ECID[1] → web ECID (primary: false)
